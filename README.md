# muhammadbayoumi.github.io

Personal website of Muhammad Bayoumi — live at **https://muhammadbayoumi.github.io**

Plain HTML, CSS and JavaScript with no build step; GitHub Pages serves the `main` branch as is.
The look follows the [mbiXsite](https://github.com/muhammadbayoumi/mbiXsite) design tokens.

```
index.html            the page
assets/css/style.css  styles
assets/js/main.js     navbar, years-of-experience counter
```
